## 使用

本地打开 `index.html`。保留整个目录；各单元共用 `assets` 中的图片与媒体。

网页使用适合投影的 WebP 图片（最长边不超过 1600，高度不超过 1200），原图保留。音视频与原始 PNG 分卷存储在本仓库 Releases，避免 Git 和各单元重复携带大文件。其他电脑可在本目录运行 `安装共享音视频.ps1`，逐个下载并校验音视频；已有文件不会被覆盖。

在下载后的课件库目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\安装共享音视频.ps1
```

此命令仅对本次脚本进程允许运行，不改变系统设置。脚本会校验已有媒体并补齐缺少的媒体；完整 D 盘版本已经安装，无需再次下载。
