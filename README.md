# 校本课件

[打开公开校本课件](https://chaoimhinalmansour.github.io/qunxiantech.github.io/)

Book 2–3，Units 1–8，LS 与 RW，共 32 个单元。标准画布 **1920 × 1080**，按屏幕尺寸等比适配。

转换包含原 PPT 的题面、图片、图表、原题选择、集中讲评、同页答案、解析、参考材料、音视频、逐句精听、内部跳转及原备注。沿用已批准的原题选用方案，不改题、不合并题目。

## 使用

本地打开 `index.html`。保留整个目录；各单元共用 `assets` 中的图片与媒体。

仓库中的网页图片为 WebP，保持原尺寸。音视频与原始 PNG 分卷存储在本仓库 Releases，避免 Git 和各单元重复携带大文件。其他电脑可在本目录运行 `安装共享音视频.ps1`，逐个下载并校验音视频；已有文件不会被覆盖。

## 内容索引

- `index.html`：32 单元课件入口
- `resources.html`：共享资源索引
- `guide.html`：课堂操作说明
- `audit/原题选用与知识能力.html`：80 模块、452 道原题、129 项原讲解材料
- `audit/原课件备注与来源.html`：原备注及教材来源
- `audit/核对记录.html`：全量核对记录

本地完整库与制作、验收记录位于 D 盘项目目录。原教材和原 PPT 保留。

## 其他 Windows 电脑安装媒体

在下载后的课件库目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\安装共享音视频.ps1
```

此命令仅对本次脚本进程允许运行，不改变系统设置。脚本会校验已有媒体并补齐缺少的媒体；完整 D 盘版本已经安装，无需再次下载。


## HTML 课堂操作更新

- 组内原题按原题号直接选择，讲评在当前题目展开。
- 原文章、图表、写作步骤和修改清单在当前课件中查看，支持并列与放大。
- 逐句精听在当前课件中展开，关闭会停止播放。
- 原题数据文件保持不变，词汇例句、既有额外练习和讲评解析保留。
- 教材原标题、概念和指令保留，三个部分的原题选用方案保持不变。

## 题目与素材更新

- 当前原题功能栏直接显示原答案、解析与参考答案入口；答案默认隐藏。
- 取消独立“本组任务”展示页，旧入口转到对应原题。
- 原题所需图片、文章、视频、其他原题及教材参考页逐项关联；共享图片集保持完整。
- 非视频听力支持完整播放、逐句播放、多句选择播放、循环、变速与教师控制原文显示。
- 题目与实际材料并列显示，支持调整题目宽度及放大材料。关闭材料停止播放。
- 32 个课件数据及 224 个原音频句子数据文件保持逐字节一致。显示层从教材恢复 32 条完整指令（含续页及六道缺题号原题），补回 6 页教材参考页，并显示教材原图表。

关联图见 `audit/题目素材关联图.html`；本次全量核对记录见 `audit/题目素材功能核对.html`。
